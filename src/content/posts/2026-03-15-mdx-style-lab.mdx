## 表格

| 字段 | 类型 | 默认值 | 是否必填 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `title` | 字符串 | 无 | 是 | 文章标题 |
| `pubDate` | 日期 | 无 | 是 | 文章发布时间 |
| `tags` | 字符串数组 | `[]` | 否 | 标签集合 |
| `description` | 字符串 | `""` | 否 | 首页摘要与 SEO 描述 |
| `featured` | 布尔值 | `false` | 否 | 是否作为首页精选展示 |

## 代码块

```ts
type PostMeta = {
  title: string;
  pubDate: string;
  tags: string[];
};

export function formatMeta(meta: PostMeta) {
  return `${meta.title} - ${meta.pubDate} - ${meta.tags.join(", ")}`;
}
```
